# 🎮 Minecraft Blender Shorts

AI-generated Blender Python scripts for Minecraft-style YouTube Shorts.

## How to Use

1. Open Blender
2. Go to **Scripting** tab
3. Click **New** → paste the script → click **▶️ Run**
4. Press **Ctrl+F12** to render

## Scripts

- `scripts/sandblock_falling.py` — Sand block falling on grass with physics simulation

## Requirements

- Blender 4.x+
- NVIDIA GPU (CUDA) recommended
